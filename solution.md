### Step-by-Step Instructions

1. **Install Software:**
* Download and install **Visual Studio Code** (VS Code).
* Download and install the **LTS (Long Term Support) version of Node.js**.


2. **Install VS Code Extensions:**
* Open VS Code, go to the Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X`), and install:
* **Live Server** (by Ritwick Dey)
* **Prettier - Code formatter** (by Prettier)




3. **Create the Project Folder & Files:**
* Create a folder named `web-development-practice` on your computer.
* Open that folder in VS Code and create three files inside it:
* `index.html`
* `style.css`
* `script.js`




4. **Run with Live Server:**
* Open `index.html` in VS Code, right-click anywhere in the file, and select **Open with Live Server** to view it in your browser.


5. **Verify Node.js Installation:**
* Open your terminal (or Command Prompt / PowerShell) and run:
```bash
node -v
npm -v

```
